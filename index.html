Python desde cero, explicado con nuestras propias palabras

Esta guía junta lo esencial para empezar en Python: variables, tipos de datos, condicionales, bucles y, sobre todo, funciones — qué son, cómo se usan y por qué existen. Cada explicación está pensada para que otro estudiante la entienda sin depender de la documentación oficial.

01 — lo primero que hay que saber

Variables y tipos de datos

Antes de escribir cualquier programa, Python necesita un lugar donde guardar la información con la que va a trabajar. Ese lugar es la variable.

¿Qué es una variable?

Una variable es simplemente un nombre que le ponemos a un valor para poder usarlo después. Es como una caja con una etiqueta: adentro guardas algo (un número, una palabra, una lista) y en la etiqueta escribes cómo se llama esa caja, para poder pedirla de nuevo más adelante.

edad = 16
nombre = "Camila"
promedio = 4.3

En Python no hay que avisar de qué tipo va a ser la caja: el lenguaje lo descubre solo, según lo que le pongas dentro.

Los tipos de datos básicos

Cada valor que guardamos tiene una naturaleza distinta, y Python la clasifica en tipos:

int — números enteros

Números sin decimales, positivos o negativos. Sirven para contar cosas: edades, cantidades, puntajes.

vidas = 3

float — números decimales

Números con coma (o punto, en Python). Se usan cuando la precisión importa: precios, promedios, medidas.

precio = 12.99

str — texto

Cualquier cadena de caracteres, entre comillas. Sirve para nombres, mensajes, respuestas de un usuario.

saludo = "Hola, mundo"

bool — verdadero o falso

Solo puede valer True o False. Es la base de toda decisión que tome el programa.

esta_aprobado = True
Operadores: cómo se combinan los valores

Los operadores son los símbolos que le dicen a Python qué hacer con los valores: sumarlos, compararlos, combinarlos.

Aritméticos

+ - * / funcionan como en matemáticas. // divide y descarta el resto, % devuelve solo el resto, y ** eleva a una potencia.

7 // 2   # 3
7 % 2    # 1
2 ** 3   # 8

De comparación

== != > < >= <= comparan dos valores y siempre devuelven un bool.

edad >= 18   # True o False
02 — decisiones y repeticiones

Condicionales y bucles

Un programa que solo ejecuta líneas de arriba hacia abajo, sin decidir nada, es poco útil. Estas dos herramientas le dan a Python la capacidad de reaccionar y de repetir tareas.

if / elif / else — tomar decisiones

Le dicen a Python: "si esta condición se cumple, haz esto; si no, prueba con esta otra; y si ninguna se cumple, haz esto último".

if nota >= 4.5:
    print("Aprobado")
elif nota >= 3.0:
    print("Necesita refuerzo")
else:
    print("Reprobado")
En nuestras palabras: es exactamente como decidir qué hacer según el clima — "si llueve, llevo paraguas; si no, salgo tranquilo". Python revisa la condición en orden y ejecuta solo el primer bloque que resulte verdadero.

for — repetir un número conocido de veces

Recorre uno por uno los elementos de algo (una lista, un rango de números, las letras de una palabra) y repite el mismo bloque de código para cada uno.

for numero in range(1, 4):
    print(numero)
# imprime 1, 2 y 3
En nuestras palabras: es como repartir un examen alumno por alumno — sabes exactamente cuántas veces vas a repetir la acción, porque sabes cuántos alumnos hay.

while — repetir mientras algo sea cierto

Repite un bloque de código una y otra vez mientras la condición siga siendo verdadera. Se usa cuando no sabemos de antemano cuántas repeticiones harán falta.

intentos = 0
while intentos < 3:
    print("Intento", intentos)
    intentos = intentos + 1
En nuestras palabras: es como seguir tocando timbre hasta que alguien abra la puerta — no sabes cuántas veces vas a tocar, solo sabes cuándo parar.
03 — el corazón de esta guía

Funciones

Una función es un bloque de código con nombre propio que recibe algo, hace un trabajo con eso, y (casi siempre) entrega un resultado. En nuestras palabras: es una pequeña máquina reutilizable. Le metes algo por un lado, ella lo procesa, y te devuelve algo por el otro — sin que tengas que reescribir el proceso cada vez.

Anatomía de una función propia

palabra clave def nombre de la función parámetros (las entradas) resultado con return
def calcular_promedio(notas):
    suma = sum(notas)
    return suma / len(notas)

Cuando llamamos calcular_promedio([4.0, 3.5, 5.0]), Python entra a ese bloque, hace el cálculo con esos valores concretos y nos devuelve un solo número: el promedio.

Funciones incorporadas (built-in)

Python ya trae funciones listas para usar, sin que nadie tenga que definirlas. Están siempre disponibles.

len("Python")   # 6
print("Hola")   # muestra "Hola"
type(5)         # <class 'int'>
max(3, 9, 1)    # 9
En nuestras palabras: son herramientas de fábrica — vienen incluidas con el lenguaje porque se usan tanto que no tendría sentido que cada quien las volviera a programar.

Funciones propias (definidas por nosotros)

Cuando una tarea se repite en nuestro propio programa, la empaquetamos en una función con def, le damos un nombre y la reutilizamos cuantas veces haga falta.

def es_par(numero):
    return numero % 2 == 0

es_par(8)   # True
es_par(7)   # False
En nuestras palabras: es escribir nuestra propia herramienta a medida, para no repetir el mismo código varias veces en distintas partes del programa.

Parámetros vs. argumentos

El parámetro es el nombre que aparece en la definición de la función (el "espacio en blanco" que espera un valor). El argumento es el valor real que le pasamos cuando la llamamos.

def saludar(nombre):   # nombre = parámetro
    print("Hola,", nombre)

saludar("Luis")        # "Luis" = argumento

¿Por qué usar return?

return hace que la función entregue un valor que se puede guardar o reutilizar en otra parte del programa. Sin él, la función puede hacer algo (como imprimir en pantalla), pero no deja nada disponible para usar después.

def duplicar(numero):
    return numero * 2

resultado = duplicar(5)
print(resultado)   # 10

06 — para consultar rápido

Glosario en palabras simples

Los mismos temas del menú de navegación del proyecto, cada uno con su explicación, un ejemplo de código y el resultado que produce.

1. print()

print() sirve para mostrar información en la pantalla. Podemos utilizarlo para mostrar textos, números o resultados de operaciones.

Ejemplo
print("Hola mundo")
Resultado
Hola mundo

2. Variables

Las variables sirven para guardar información dentro del programa. Una variable puede almacenar un nombre, una edad, un número, etc.

Ejemplo
nombre = "Juan"
edad = 17

print(nombre)
print(edad)
Resultado
Juan
17

3. input()

input() permite que el programa reciba información escrita por el usuario.

Ejemplo
nombre = input("Escribe tu nombre: ")
print("Hola", nombre)
Resultado
Escribe tu nombre: Carlos
Hola Carlos

4. Operaciones

Python permite realizar operaciones matemáticas como sumar, restar, multiplicar y dividir. Los principales operadores son:

+ → Suma  ·  - → Resta  ·  * → Multiplicación  ·  / → División  ·  % → Resto de una división

Ejemplo
a = 10
b = 5

print(a + b)
print(a - b)
print(a * b)
print(a / b)
Resultado
15
5
50
2.0

5. int y float

int se utiliza para trabajar con números enteros, mientras que float se utiliza para números decimales.

Ejemplo
edad = int("17")
altura = float("1.75")

print(edad)
print(altura)
Resultado
17
1.75

También son muy utilizados con input() para convertir lo que escribe el usuario en un número.

6. if / else

if y else permiten que el programa tome decisiones. if significa "si se cumple esta condición" y else significa "si no se cumple".

Ejemplo
edad = 18

if edad >= 18:
    print("Eres mayor de edad")
else:
    print("Eres menor de edad")
Resultado
Eres mayor de edad

7. if / elif / else

Se utiliza cuando necesitamos comprobar varias condiciones diferentes: if comprueba la primera condición, elif comprueba otra condición si la anterior no se cumplió, y else se ejecuta si ninguna condición se cumple.

Ejemplo
nota = 4

if nota >= 4.5:
    print("Excelente")
elif nota >= 3:
    print("Aprobaste")
else:
    print("Reprobaste")
Resultado
Aprobaste

8. while

while permite repetir un bloque de código mientras una condición sea verdadera.

Ejemplo
numero = 1

while numero <= 5:
    print(numero)
    numero = numero + 1
Resultado
1
2
3
4
5

Es importante modificar la variable para que la condición eventualmente deje de cumplirse y el ciclo termine.

9. for

for permite repetir instrucciones una cantidad determinada de veces o recorrer elementos, como los de una lista.

Ejemplo
for numero in range(5):
    print(numero)
Resultado
0
1
2
3
4

range(5) genera los números desde 0 hasta 4.

10. Listas

Las listas permiten guardar varios datos dentro de una sola variable. Se escriben utilizando corchetes [].

Ejemplo
frutas = ["manzana", "pera", "uva"]

print(frutas)
Resultado
['manzana', 'pera', 'uva']

También podemos acceder a un elemento específico utilizando su posición:

print(frutas[0])
Resultado
manzana
